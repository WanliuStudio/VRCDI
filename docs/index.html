它能做什么

13 项可勾选字段，按你的选择分段拼成多行文本，走 UDP OSC 发给 VRChat。

采集

13 项设备信息

品牌、型号、CPU 名称 / 频率 / 温度 / 使用率、GPU 名称 / 频率 / 温度 / 使用率、RAM、电量与充电状态、前台应用。

权限

三种通道

Shizuku（shell 身份）、Root（自动识别 KernelSU / APatch / Magisk 系）、免授权兜底。读不到的指标显示「不可用」，不编造数值。

发送

OSC Chatbox

通过 /chatbox/input 发送，目标可选本机 127.0.0.1 或自定义 IP，支持立即发送、提示音与仅 ASCII。

限制

144 字符自适应

遵守 Chatbox 单条上限，超长时按字段优先级从末尾丢弃，并在预览区提示「已自动省略」，不会静默截断。

设备表

型号 → 产品名称

按品牌导入 JSON 设备表，可在「设备真实型号」与「设备产品名称」之间切换，无需重新编译。

主题

可换肤

导入 zip / tar.gz 主题包，内含背景图、按钮图与配色；切换后自动重启生效。

分段

多行显示

每类信息单独一行：品牌型号 / CPU / GPU / RAM / 电量 / App，超出 144 字符时自动整段裁剪。

应用表

包名 → 应用名

导入包名映射后，前台应用显示成「微信」「QQ」「VRChat」这样的名字，而不是一串包名。

更新

应用内更新

可选 Gitee / GitHub 更新源，以及「正式版 / 测试版」更新频道；检查新版本、在页面内查看日志并直接下载安装。

怎么用

装好之后四步就能发。

授权右上角齿轮 → 权限申请方式，完成 Shizuku 或 Root 授权；也可以直接选「免授权」。
选目标VRChat 和手机在同一台设备选「本机IP」；手机发给 PC 选「自定义...」填 PC 的局域网 IP。
开 OSCVRChat 动作菜单 → Options → OSC → Enabled。跨设备时给 VRChat 加启动参数 --osc=9000:<PC 的局域网 IP>:9001。
启动上报勾选要展示的字段，点「启动上报」，Chatbox 里就能看到设备信息。

已知限制

GPU 数据最不可靠：安卓没有公开 API 获取 GPU 频率 / 温度 / 占用，靠厂商各自的 sysfs 节点，很多机型即使有 root 也读不到。

Quest 一体机可以安装运行，但无 root、Shizuku 非官方支持，温度频率基本不可用。

前台应用需要系统「使用情况访问」权限，未授权时该字段显示「不可用」。

设备表、主题、应用表与应用内更新都还在早期阶段，遇到问题欢迎到仓库提 Issue。

下载提示：当前为 5.1.0 Beta2 测试版，使用发布私钥签名； 4.9.0 及之后的版本可直接覆盖升级，4.4.4 Beta 及更早的 debug 签名版本需要先卸载再安装。 开发者验证（ADV）需要在手机厂商开放平台完成注册后由平台自动提交，目前尚未完成， 部分设备安装时可能提示「未验证开发者」，可手动确认继续安装。 安装前请确认系统为 Android 10（API 29）及以上。

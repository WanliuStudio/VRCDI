VRCDI / 设备信息 · OSC · Chatbox

通过 Shizuku 或 Root 读取安卓设备的 CPU、GPU、内存与电量，用 OSC 实时显示在 VRChat 的聊天框里。

SHA-256:

它能做什么

13 项可勾选字段，按你的选择拼成一行文本，走 UDP OSC 发给 VRChat。

采集

13 项设备信息

品牌、型号、CPU 名称 / 频率 / 温度 / 使用率、GPU 名称 / 频率 / 温度 / 使用率、RAM、电量与充电状态、前台应用。

权限

三种通道

Shizuku（shell 身份）、Root（自动识别 KernelSU / APatch / Magisk 系）、无特权兜底。读不到的指标显示「不可用」，不编造数值。

发送

OSC Chatbox

通过 /chatbox/input 发送，目标可选本机 127.0.0.1 或自定义 IP，支持立即发送、提示音与仅 ASCII。

限制

144 字符自适应

遵守 Chatbox 单条上限，超长时按字段优先级从末尾丢弃，并在预览区提示「已自动省略」，不会静默截断。

设备表

型号 → 产品名称

按品牌导入 JSON 设备表，可在「设备真实型号」与「设备产品名称」之间切换，无需重新编译。

主题

可换肤

导入 zip / tar.gz 主题包，内含背景图、按钮图与配色；切换后自动重启生效。

怎么用

装好之后三步就能发。

授权右上角齿轮 → 权限申请方式，完成 Shizuku 或 Root 授权；不授权也能用无特权模式。
选目标VRChat 和手机在同一台设备选「本机IP」；手机发给 PC 选「自定义...」填 PC 的局域网 IP。
开 OSCVRChat 动作菜单 → Options → OSC → Enabled。跨设备时给 VRChat 加启动参数 --osc=9000:<PC 的局域网 IP>:9001。
启动上报勾选要展示的字段，点「启动上报」，Chatbox 里就能看到设备信息。

已知限制

GPU 数据最不可靠：安卓没有公开 API 获取 GPU 频率 / 温度 / 占用，靠厂商各自的 sysfs 节点，很多机型即使有 root 也读不到。

Quest 一体机可以安装运行，但无 root、Shizuku 非官方支持，温度频率基本不可用。

前台应用需要系统「使用情况访问」权限，未授权时该字段显示「不可用」。

设备表与主题为首次加入，遇到问题欢迎到仓库提 Issue。

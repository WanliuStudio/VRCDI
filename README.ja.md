# VRCDI

> Android デバイスの状態をリアルタイムで VRChat のチャットボックスへ。

VRCDI は純 Java で書かれた小さな Android アプリです。**Shizuku**（または Root、あるいは権限なし）経由で CPU / GPU / メモリ / バッテリーなどを読み取り、チェックした項目を複数行のテキストにまとめ、**UDP OSC** の `/chatbox/input` で VRChat に送信します。アバターの頭上に出るチャットボックスに表示されます。

- パッケージ名：`com.vrcdevicecheck.osc`
- バージョン：`5.3.0 Beta4 (Build 451)`
- 署名：**4.9.0 Release** 以降、Beta 版と正式版は同じリリース鍵で署名されます。4.4.4 Beta 以前の APK は debug 署名のため、アップデート時は先にアンインストールが必要です（アプリデータは消えます）。
- 最低要件：Android 10（API 29）
- 言語：Java 8。サードパーティ依存は Shizuku のみ
- ビルド：Android Studio 4.2 / AGP 4.2.2 / Gradle 6.7.1 / compileSdk 30

> **公式サイト：https://wanliustudio.github.io/VRCDI/**
>
> ダウンロードは公式サイト、[GitHub Releases](https://github.com/WanliuStudio/VRCDI/releases)、

> 出所不明の APK はインストールしないでください。

## 機能

**データ取得**

- 21 個の選択可能な項目：デバイスのブランド、型番、CPU 名 / 周波数 / 温度 / 使用率、GPU 名 / 周波数 / 温度 / 使用率、RAM 使用量 / 総量、バッテリー残量と充電状態、天気 / 気温 / 湿度 / 気圧 / 風向風速 / 紫外線 / 日の入り、前面アプリ、フレームレート。
- 出力は**行ごとに分割**され、分類ごとに 1 行になります。例：
  ```
  OPPO PCAT00
  CPU: Qualcomm SM8550 2.21GHz 46.1℃ 10%
  GPU: Adreno 740 利用不可 41.3℃ 利用不可
  RAM: 3.9/5.5GB 71%
  バッテリー: 45% 充電中
  App: VRCDI（本アプリ）
  ```
- sysfs / procfs のノードは**1 つのシェルスクリプト**（`assets/snapshot.sh`）でまとめて読むため、1 周期につき子プロセスは 1 回だけです。
- 取得できない値は「利用不可」と表示し、数値をでっち上げることはありません。

**3 つの権限チャネル**

| チャネル | 説明 |
| --- | --- |
| Shizuku | shell（uid 2000）権限で実行。Shizuku のインストールと起動が必要 |
| Root | `su` で直接実行。root ライブラリは同梱せず、KernelSU / APatch / Magisk 系を判別して許可へ誘導 |
| 権限なし | 通常アプリに公開されているノードのみ。CPU 温度 / 周波数はほぼ利用不可 |

**OSC 送信**

- 送信先は**この端末**（`127.0.0.1`、VRChat と VRCDI が同じ端末の場合）または**任意の IP**（スマホ → PC の VRChat）を選べます。
- `/chatbox/input` の「即時送信」と「通知音」の両方に対応。
- チャットボックスは 1 通 **144 文字**まで。超えた場合は優先度の低い項目から末尾を削り、プレビューに「省略：xxx」と正直に表示します。

**送信間隔**

- 設定（右上の歯車）→ **送信間隔**：2 / 5 / 10 / 30 / 60 秒、または任意の **2〜3600 秒**。
- 「送信開始時に 1 回すぐ送る」は既定でオン。開始を押すと即座に取得・送信し、その後は間隔ごとに繰り返します。
- 送信中に保存すると、古い周期を待たず**すぐに新しい間隔で再スケジュール**され、通知の「X 秒ごと」も更新されます。
- 間隔が短いほど更新は速くなりますが電池を食います。VRChat は現在 **5 秒間に 5 通**程度まで（以前はもっと厳しい）なので、更新されない場合は間隔を広げてください。

**利用不可の自動非表示**

- 項目カードの下部に「利用不可の項目を自動で隠す」スイッチがあり、**既定でオン**です。
- 「利用不可」の項目はテキストに含めず、144 文字も消費しません。画面には「利用不可の項目を N 件隠しました」と表示されます。
- オフにすると従来どおり「利用不可」と表示します。
- 「隠した項目」と「144 文字超過で落とした項目」は別々に数えるので、超過警告が誤って出ることはありません。

**天気**

- 設定（歯車）→ **天気の都市設定**：中国国内は省 → 市の 2 段階。34 の省級行政区、346 都市を内蔵。
- **海外の都市にも対応**：
  - 一覧の先頭「都市を検索」で世界中の都市を名前で検索（中国語・英語どちらでも、例：`Tokyo` / `东京`）。
  - 一覧の末尾「海外から選ぶ」で**国 → 都市**をたどれます。240 か国 / 2100 以上の都市を内蔵し、オフラインでも閲覧可能。
  - どちらの経路でも緯度経度を直接保存し、3 つのデータソースはすべて座標で問い合わせます（都市名の解決に依存しません）。
- 検索結果は人口の多い順。漢字で検索した場合は繁体字でも再検索するので（东京 → 東京）、国内の同名小都市だけがヒットすることはありません。
- 追加項目：**天気 / 気温 / 湿度 / 気圧 / 風向風速 / 紫外線 / 日の入り**。既定ではオフで、都市未選択のままオンにすると設定へ誘導します。
- 天気は 2 行：1 行目が天気 / 気温 / 湿度、2 行目が気圧 / 風 / 紫外線 / 日の入り。文字数超過時は 2 行目から落とし、基本情報を残します。
- 風は 8 方位（例：「南西の風 3.2m/s」）、気圧は hPa、紫外線は 0〜11+ の指数、日の入りは現地時刻 HH:mm。
- 第一候補は **Open-Meteo**（無料・キー不要）。`api.open-meteo.com` に届かない場合は **wttr.in**（同じく無料・キー不要）へ自動で切り替えます。
- **30 分キャッシュ**：取得成功時にタイムスタンプを SharedPreferences に書き込み、同じ都市は 30 分間再取得しません。プロセス終了や再起動でも保持されます。失敗後は 10 分間リトライしません。
- 手動の「今すぐ取得」も同じ 30 分制限を受けます。同じ都市で再度押すと残り時間を表示し、**都市を変えるとキャッシュが消える**ので切り替え後はすぐ取得できます。
- 位置情報権限は不要で、選んだ都市だけを問い合わせ、天気データは端末内にのみ保存します。

**デバイス表（型番 → 製品名）**

- ブランドごとにデバイス表 JSON をインポートすると、アプリ専用ディレクトリ `files/device_tables/<ブランド>.json` にコピーされます。再ビルドは不要です。
- 「報告する型番の種類」で**実際の型番**（例：`HUAWEI HED-AL00`）と**製品名**（例：`HUAWEI Pura 80`）を切り替えられます。

**テーマ**

- **内蔵配色**：設定 → テーマから直接選択。クリムゾン / ミストブルー / さくら / パイン / アンバー / バイオレット。背景・カード・本文・補助文字の 4 色だけを置き換え、すぐ反映されます。
- 内蔵配色はすべてライト系です。ダークな見た目にはボタンや入力欄の素材が必要で、下記のテーマ読み込みを使います。
- `.zip` / `.tar.gz` のテーマパッケージを読み込むと `files/themes/<テーマ名>/` に展開されます。
- 背景画像、ボタン画像（押下状態を含む）、配色 JSON を同梱でき、素材が必要な凝った外観に向きます。
- 切り替え後はアプリが自動で再起動します。設定画面で長押しすると読み込んだテーマを削除できます（内蔵配色は削除不可）。

**アプリ表（パッケージ → アプリ名）**

- 主要アプリ（QQ、WeChat、VRChat など）を内蔵し、独自の JSON で上書きもできます。
- 「前面アプリ」はアプリ表 → システムのアプリ名 → パッケージ名の順に表示します。

**アプリ内アップデート**

- 設定 → ソフトウェア更新設定で **Gitee** か **GitHub** を更新元として選択。
- リリース API から最新タグを取得して現在のバージョンと比較し、新しければ添付ファイルをダウンロードしてシステムのインストーラーに渡します。
- ダウンロードした APK は `cache/update/` に保存され、添付名が `.apk.zip` の場合は自動的に `.apk` として扱います。

**表示言語**

- 設定 → **言語 / 语言**：简体中文（既定）、English、日本語、Русский、한국어。切り替え後はアプリが再起動します。
- **VRChat のチャットボックスに送るテキストも表示言語に追従**します（中国語・英語・日本語・ロシア語・韓国語）。144 文字の上限は変わりません。
- 「ASCII のみ送信」が言語より優先されます。オンにすると英語の ASCII 表記に固定され（`℃` → `C`）、VRChat で疑問符になるのを防げます。
- 中国語が既定で `values/`、他は `values-en` / `values-ja` / `values-ru` / `values-ko` にあり、5 言語のキーは 1 対 1 で対応しています。
- 日本語・ロシア語・韓国語の画面では、地名と天気の文言に英語データを使います（内蔵の都市データは中国語と英語のみ）。

**初回起動ガイド**

- 新規インストールでは、最初に言語の選択（各言語をその言語で表記）を求め、選ぶとすぐ切り替わります。
- 続いて「VRChat で OSC をオンにする」図解チュートリアル（実写スクリーンショット 5 枚 + 各 1 文、言語ごとに 1 セット）を表示します。
- 旧バージョンからアップデートした場合は表示されません（既存の設定があればガイド済みとみなします）。
- 設定 → **OSC 設定ガイド** からいつでも見直せます。

**その他**

- 前面サービスで常時送信し、通知からその場で停止できます。ログはメモリ上に最新 50 件のみ保持します。
- 「前面アプリ」の検出（システムの「使用状況へのアクセス」権限が必要）。

## インストールと使い方

1. APK をインストール（Releases ページ、または自分でビルド）。
2. アプリを開くと、初回は言語選択と「VRChat で OSC をオンにする」チュートリアルが表示されます（設定 → **OSC 設定ガイド** で再表示可）。
3. 右上の**歯車**から設定を開きます：
   - **送信間隔**：2〜3600 秒、開始時に 1 回すぐ送るかどうか。
   - **天気の都市設定**：省 → 市で場所を選択。
   - **権限の要求方法**：Shizuku / Root / 権限なし。
   - **デバイス表設定**：ブランド別の表をインポート（任意）。
   - **アプリ表設定**：パッケージ → アプリ名の対応をインポート（任意）。
   - **テーマ**：テーマの読み込みと切り替え（任意）。
   - **ソフトウェア更新設定**：更新元の選択と確認／インストール。
   - **VRCDI について**：バージョン、作者、デバイス情報（CPU / GPU を含む）。
4. **接続設定**で送信先を選びます：
   - VRChat と VRCDI が同じ端末 → **この端末**。
   - スマホから PC の VRChat へ → **カスタム...** を選び、PC の LAN IP を入力。
5. **報告項目**で表示したい項目にチェック（型番の行は実型番 / 製品名を切り替え可能）。
6. **送信開始**を押します。通知に前面サービスの通知が出て、そこから停止できます。

### VRChat 側（PC に送る場合は必須）

1. VRChat のアクションメニュー → Options → OSC → **Enabled**。
2. VRChat は既定で `127.0.0.1` しか待ち受けません。別端末から送るには起動オプションを追加します（Steam → プロパティ → 起動オプション）：

   ```
   --osc=9000:<PC の LAN IP>:9001
   ```

   アプリのメイン画面がこの行を組み立てて表示するので、そのままコピーできます。
3. PC のファイアウォールで UDP 9000 を許可し、そのポートをフェイストラッキング／ボディトラッキングのソフトが使っていないことを確認します。

> 補足：OSC は片方向で、UDP に到達確認はありません。ログの「送信済み」は、データグラムを OS のネットワークスタックに渡したことだけを意味します。実際に届いたかは VRChat のアクションメニューにある OSC Debug パネルで確認してください。

## デバイス表の形式

`デバイス表設定 → ブランド別に作成`：ブランド名を入力し JSON ファイルを選ぶと、そのまま `files/device_tables/<ブランド>.json` にコピーされます。

```json
{
  "devices": [
    { "model": "HED-AL00", "match": "exact",  "series": "Pura 80",     "verified": true },
    { "model": "LMR-AL",  "match": "prefix", "series": "Pura 80 Pro", "verified": false }
  ]
}
```

| フィールド | 必須 | 説明 |
| --- | --- | --- |
| `model` | はい | `ro.product.model` / `Build.MODEL` に対応する型番。比較は大文字小文字を無視 |
| `series` | はい | 「製品名」を選んだときに表示される名前 |
| `match` | いいえ | `exact`（既定、完全一致）または `prefix`（型番が前方一致。派生モデル向け） |
| `verified` | いいえ | 注記用。表示には使われません |

- 最上位をそのまま配列にしても構いません。ファイルは UTF-8（BOM 付きも可）。
- 読み込み順：`files/device_tables/*.json` → 旧形式 `files/device_models.json` → 内蔵 `assets/device_models.json`。先に一致したものが優先。
- 製品名はまずシステムプロパティ（`ro.product.marketname` など）から取り、取れない場合にデバイス表を参照します。

## テーマパッケージの形式

`.zip` と `.tar.gz` / `.tgz` に対応。展開後に `theme.json` が必要です：

```
mytheme.zip
├── theme.json                 # 必須
└── images/
    ├── background.png         # 任意、ウィンドウ背景
    ├── button.png             # 任意、ボタン通常時
    └── button_pressed.png     # 任意、ボタン押下時
```

```json
{
  "name": "夜間飛行",
  "colors": {
    "background": "#0F1216",
    "card": "#1A1F24",
    "text": "#E8EAED",
    "textSecondary": "#A0A8B0"
  },
  "images": {
    "background": "images/background.png",
    "button": "images/button.png",
    "buttonPressed": "images/button_pressed.png"
  }
}
```

- `name` 以外はすべて任意。色は `#RRGGBB` / `#AARRGGBB`、画像パスはテーマディレクトリからの相対パス。
- テーマ名がディレクトリ名になります。同名を再読み込みすると上書きされます。
- 切り替え後はアプリが自動で再起動します。設定画面で長押しすると削除できます。

## ソースからビルド

```bash
./gradlew assembleDebug      # app/build/outputs/apk/debug/app-debug.apk を生成
./gradlew test               # JVM 単体テスト（OSC エンコード、解析、テキスト生成など）
```

- JDK 11 と Android SDK 30（build-tools 30.0.3）が必要です。
- 本プロジェクトは意図的に「純 Java + AndroidX の UI コンポーネントなし」を保っています。画面はすべて `android.app.Activity` と素の View で作られており、古い環境（Android Studio 4.2 など）でもビルドできます。
- 唯一のサードパーティ依存は `dev.rikka.shizuku:api` / `provider`（12.1.0）で、これが `androidx.annotation` を推移的に要求するため `gradle.properties` に `android.useAndroidX=true` が必要です（AppCompat は入らず、画面はすべてネイティブ Activity のままです）。

### アプリアイコン

リポジトリにアイコンの原画は含まれていません。原画を用意したら一度だけ実行してください：

```powershell
powershell -ExecutionPolicy Bypass -File tools\make_icons.ps1 -Source "画像のパス"
```

各密度の `ic_launcher.png` とアダプティブアイコンの前景を生成し、`mipmap-anydpi-v26` のアイコン XML を新しい前景に差し替えます。

## 既知の制限

- **GPU の情報が最も不確実**：Android には GPU の周波数 / 温度 / 使用率を取る公開 API がなく、メーカー固有の sysfs ノードに依存します。Unisoc や一部の MediaTek 端末では root があっても読めず「利用不可」になります。GPU 名はまず GL の `GL_RENDERER`（権限不要）を使い、取れない場合のみ sysfs に戻ります。
- **チャットボックスのレート制限**：コミュニティの計測では「5 秒間に 5 通」程度。超えるとクールダウンに入ります。既定の 10 秒間隔は保守的な値です。
- **非 ASCII の表示**：転送は常に UTF-8 ですが、VRChat のバージョンによって非 ASCII の対応が異なります。「ASCII のみ送信」をオンにすると確実に表示されます。
- **Quest 単体**：インストールして動作しますが、Quest には root がなく Shizuku も正式対応ではないため、温度 / 周波数はほぼ取得できません。Quest 版 VRChat が OSC 入力を受け付けるかはシステム版本に依存するため、ご自身で確認してください。
- **前面アプリの検出**にはシステムの「使用状況へのアクセス」権限が必要です。未許可の場合、その項目は「利用不可」になります。

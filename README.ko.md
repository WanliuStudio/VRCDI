# VRCDI

> 안드로이드 기기의 실시간 상태를 VRChat 채팅창으로 보냅니다.

VRCDI는 순수 Java로 만든 작은 안드로이드 앱입니다. **Shizuku**(또는 Root, 또는 권한 없이)를 통해 CPU / GPU / 메모리 / 배터리 등을 읽고, 체크한 항목을 여러 줄 텍스트로 묶어 **UDP OSC**의 `/chatbox/input`으로 VRChat에 보냅니다. 아바타 머리 위에 뜨는 채팅창(Chatbox)에 표시됩니다.

- 패키지: `com.vrcdevicecheck.osc`
- 버전: `5.1.0 Beta2 (Build 431)`
- 서명: **4.9.0 Release**부터 Beta와 정식 빌드가 같은 릴리스 키로 서명됩니다. 4.4.4 Beta 이전 빌드는 debug 서명이라 업데이트하려면 먼저 삭제해야 합니다(앱 데이터가 지워집니다).
- 최소 사양: Android 10 (API 29)
- 언어: Java 8, 서드파티 의존성은 Shizuku 하나뿐
- 빌드: Android Studio 4.2 / AGP 4.2.2 / Gradle 6.7.1 / compileSdk 30

> **공식 사이트: https://wanliustudio.github.io/VRCDI/**
>
> 다운로드는 공식 사이트, [GitHub Releases](https://github.com/WanliuStudio/VRCDI/releases),
> [Gitee 릴리스](https://gitee.com/WanliuStudio/VRCDI/releases)에서만 받으세요.
> 제3자 "다운로드 사이트"나 앱 모음 페이지가 배포하는 APK는 변조되었거나 오래된 경우가 많고,
> 설명도 실제 기능과 다른 경우가 흔합니다(VR 헤드셋/컨트롤러 검사 도구로 소개되기도 합니다).
> 출처가 불분명한 APK는 설치하지 마세요.

## 기능

**데이터 수집**

- 선택 가능한 21개 항목: 기기 브랜드, 기기 모델, CPU 이름 / 주파수 / 온도 / 사용률, GPU 이름 / 주파수 / 온도 / 사용률, RAM 사용량 / 전체, 배터리와 충전 상태, 날씨 / 기온 / 습도 / 기압 / 바람 / 자외선 / 일몰, 포그라운드 앱, 프레임레이트.
- 출력은 **줄 단위로 나뉘며** 분류마다 한 줄입니다. 예:
  ```
  OPPO PCAT00
  CPU: Qualcomm SM8550 2.21GHz 46.1℃ 10%
  GPU: Adreno 740 사용 불가 41.3℃ 사용 불가
  RAM: 3.9/5.5GB 71%
  배터리: 45% 충전 중
  App: VRCDI(이 앱)
  ```
- sysfs / procfs 노드는 **하나의 셸 스크립트**(`assets/snapshot.sh`)에서 한 번에 읽으므로 주기마다 자식 프로세스가 한 번만 생깁니다.
- 읽지 못한 값은 "사용 불가"로 표시하며, 수치를 지어내지 않습니다.

**세 가지 권한 채널**

| 채널 | 설명 |
| --- | --- |
| Shizuku | shell(uid 2000) 권한으로 실행. Shizuku 설치와 실행이 필요 |
| Root | `su`로 직접 실행하며 root 라이브러리를 포함하지 않음. KernelSU / APatch / Magisk 계열을 인식해 권한 부여로 안내 |
| 권한 없음 | 일반 앱에 공개된 노드만 읽음. CPU 온도 / 주파수는 대부분 사용 불가 |

**OSC 전송**

- 대상은 **이 기기**(`127.0.0.1`, VRChat과 VRCDI가 같은 기기일 때) 또는 **사용자 지정 IP**(휴대폰 → PC의 VRChat)입니다.
- `/chatbox/input`의 "즉시 전송"과 "알림음" 두 파라미터를 모두 지원합니다.
- 채팅창 한 건은 **144자**까지입니다. 넘으면 우선순위가 낮은 항목부터 끝에서 버리고, 미리보기에 "생략됨: xxx"이라고 그대로 알립니다.

**전송 주기**

- 설정(오른쪽 위 톱니바퀴) → **보고 시간 설정**: 2 / 5 / 10 / 30 / 60초, 또는 **2–3600초** 직접 입력.
- "보고 시작 시 즉시 한 번 전송"이 기본으로 켜져 있습니다. 시작을 누르면 바로 수집해 한 번 보내고, 이후 주기대로 반복합니다.
- 전송 중에 저장하면 이전 주기를 기다리지 않고 **즉시 새 주기로 다시 예약**되며, 알림의 "X초마다"도 함께 갱신됩니다.
- 주기가 짧을수록 갱신은 빠르지만 배터리를 더 씁니다. 현재 VRChat은 **5초에 5건** 정도까지 허용하므로(예전에는 더 엄격), 채팅창이 갱신되지 않으면 주기를 늘리세요.

**사용 불가 항목 자동 숨김**

- 항목 카드 아래에 "사용 불가 항목 자동 숨김" 스위치가 있고 **기본값은 켜짐**입니다.
- "사용 불가"로 읽힌 항목은 텍스트에 들어가지 않고 144자도 차지하지 않습니다. 화면에는 "사용 불가 항목 N개를 숨겼습니다"라고 표시됩니다.
- 끄면 예전처럼 "사용 불가"로 표시합니다.
- 숨긴 항목과 "144자 초과로 버린 항목"은 따로 집계하므로 초과 경고가 잘못 뜨지 않습니다.

**날씨**

- 설정(톱니바퀴) → **날씨 도시 설정**: 중국 내에서는 성 → 시 2단계로 선택하며 34개 성급 행정구와 346개 도시가 내장되어 있습니다.
- **해외 도시 지원**:
  - 목록 첫 항목 "도시 검색"으로 전 세계 도시를 이름으로 검색합니다(중국어/영어 모두 가능, 예: `Tokyo`).
  - 목록 마지막 항목 "해외 선택"으로 **국가 → 도시**를 탐색합니다. 240개국 / 2100개 이상 도시가 내장되어 오프라인에서도 볼 수 있습니다.
  - 두 경로 모두 위도·경도를 직접 저장하고, 세 데이터 소스가 모두 좌표로 조회합니다(도시 이름 해석에 의존하지 않음).
- 검색 결과는 인구 내림차순이며, 한자로 검색하면 번체 표기로 한 번 더 시도합니다(东京 → 東京). 중국 내 동명의 작은 도시만 걸리는 일을 줄이기 위해서입니다.
- 추가 항목: **날씨 / 기온 / 습도 / 기압 / 바람 / 자외선 / 일몰**. 기본은 꺼져 있고, 도시를 고르지 않은 채 켜면 설정으로 안내합니다.
- 날씨는 두 줄입니다. 첫 줄은 날씨 / 기온 / 습도, 둘째 줄은 기압 / 바람 / 자외선 / 일몰. 길이를 넘으면 둘째 줄을 먼저 버려 기본 정보를 남깁니다.
- 바람은 8방위(예: "남서풍 3.2m/s"), 기압은 hPa, 자외선은 0–11+ 지수, 일몰은 현지 시각 HH:mm입니다.
- 1순위 소스는 **Open-Meteo**(무료, 키 불필요)이고, `api.open-meteo.com`에 닿지 않으면 **wttr.in**(역시 무료, 키 불필요)으로 자동 전환해 제한된 네트워크에서도 날씨가 나옵니다.
- **30분 캐시**: 성공하면 타임스탬프를 SharedPreferences에 기록해 같은 도시를 30분간 다시 요청하지 않습니다. 프로세스 종료와 재부팅에도 유지됩니다. 실패 후에는 10분간 재시도하지 않습니다.
- 수동 "지금 가져오기"도 같은 30분 제한을 받습니다. 같은 도시에서 다시 누르면 남은 시간을 알려주고, **도시를 바꾸면 캐시가 지워져** 바로 가져올 수 있습니다.
- 위치 권한은 필요 없습니다. 선택한 도시만 조회하며 날씨 데이터는 기기 안에만 저장됩니다.

**기기 표(모델 → 제품명)**

- 브랜드별 기기 표 JSON을 가져오면 앱 전용 디렉터리 `files/device_tables/<브랜드>.json`으로 복사됩니다. 다시 빌드할 필요가 없습니다.
- "보고할 모델명 종류"로 **실제 모델**(예: `HUAWEI HED-AL00`)과 **제품명**(예: `HUAWEI Pura 80`)을 전환할 수 있습니다.

**테마**

- **내장 색상**: 설정 → 테마에서 바로 선택. 크림슨 / 미스트 블루 / 사쿠라 / 파인 / 앰버 / 바이올렛. 배경·카드·본문·보조 텍스트 네 색만 바꾸며 즉시 적용됩니다.
- 내장 색상은 모두 밝은 계열입니다. 어두운 모습은 버튼과 입력창 이미지가 필요하므로 아래 테마 가져오기를 사용합니다.
- `.zip` / `.tar.gz` 테마 팩을 가져오면 `files/themes/<테마 이름>/`으로 복사됩니다.
- 배경 이미지, 버튼 이미지(눌린 상태 포함), 색상 JSON을 넣을 수 있어 이미지가 필요한 복잡한 외형에 적합합니다.
- 전환 후 앱이 자동으로 다시 시작됩니다. 설정 화면에서 길게 누르면 가져온 테마를 삭제할 수 있습니다(내장 색상은 삭제 불가).

**앱 표(패키지 → 앱 이름)**

- 자주 쓰는 앱(QQ, WeChat, VRChat 등)이 내장되어 있고, 직접 만든 JSON으로 덮어쓸 수 있습니다.
- "포그라운드 앱"은 앱 표 → 시스템 앱 이름 → 패키지 이름 순으로 표시합니다.

**앱 내 업데이트**

- 설정 → 소프트웨어 업데이트 설정에서 **Gitee** 또는 **GitHub**를 업데이트 소스로 선택합니다.
- 릴리스 API에서 최신 태그를 받아 현재 버전과 비교하고, 새 버전이면 첨부 파일을 내려받아 시스템 설치 관리자로 넘깁니다.
- 내려받은 APK는 `cache/update/`에 저장되며, 첨부 이름이 `.apk.zip`이면 자동으로 `.apk`로 처리합니다.

**인터페이스 언어**

- 설정 → **언어 / 语言**: 简体中文(기본), English, 日本語, Русский, 한국어. 전환 후 앱이 다시 시작됩니다.
- **VRChat 채팅창으로 보내는 텍스트도 인터페이스 언어를 따릅니다** — 중국어, 영어, 일본어, 러시아어, 한국어. 144자 제한은 그대로입니다.
- "ASCII만 전송"이 언어보다 우선합니다. 켜면 영어 ASCII 표기로 고정되어(`℃` → `C`) VRChat에서 물음표로 보이는 일을 막습니다.
- 중국어가 기본이며 `values/`에, 나머지는 `values-en` / `values-ja` / `values-ru` / `values-ko`에 있고 다섯 세트의 키가 1:1로 대응합니다.
- 일본어·러시아어·한국어 화면에서는 지명과 날씨 문구에 영어 데이터를 사용합니다(내장 도시 DB가 중국어와 영어 이름만 보유).

**첫 실행 가이드**

- 새로 설치하면 먼저 언어 선택(각 언어를 그 언어로 표기)을 띄우고, 고르면 즉시 전환됩니다.
- 이어서 "VRChat에서 OSC 켜기" 그림 안내가 나옵니다. 실제 스크린샷 5장에 설명 한 줄씩, 언어별로 한 세트(중국어 / 영어 / 일본어 / 러시아어 / 한국어)입니다.
- 이전 버전에서 업데이트한 사용자에게는 나오지 않습니다(설정이 이미 있으면 가이드를 마친 것으로 간주).
- 설정 → **OSC 설정 가이드**에서 언제든 다시 볼 수 있습니다.

**기타**

- 포그라운드 서비스로 상시 전송하며 알림에서 바로 중지할 수 있습니다. 로그는 메모리에 최근 50건만 보관합니다.
- "포그라운드 앱" 감지(시스템의 "사용 정보 접근" 권한 필요).

## 설치와 사용

1. APK를 설치합니다(Releases 페이지 또는 직접 빌드).
2. 앱을 열면 처음에 언어 선택과 "VRChat에서 OSC 켜기" 안내가 나옵니다(설정 → **OSC 설정 가이드**에서 다시 보기).
3. 오른쪽 위 **톱니바퀴**로 설정을 엽니다:
   - **보고 시간 설정**: 2–3600초와 시작 시 즉시 전송 여부.
   - **날씨 도시 설정**: 성 → 시 순서로 위치 선택.
   - **권한 요청 방식**: Shizuku / Root / 권한 없음.
   - **기기 표 설정**: 브랜드별 표 가져오기(선택).
   - **앱 표 설정**: 패키지 → 앱 이름 매핑 가져오기(선택).
   - **테마**: 테마 가져오기와 전환(선택).
   - **소프트웨어 업데이트 설정**: 소스 선택, 확인 및 설치.
   - **VRCDI 정보**: 버전, 제작자, 기기 정보(CPU / GPU 포함).
4. **연결 설정**에서 대상을 고릅니다:
   - VRChat과 VRCDI가 같은 기기 → **이 기기**.
   - 휴대폰에서 PC의 VRChat으로 → **사용자 지정...**을 선택하고 PC의 LAN IP 입력.
5. **보고 항목**에서 표시할 항목을 체크합니다(모델 줄에서 실제 모델 / 제품명 전환 가능).
6. **보고 시작**을 누릅니다. 알림에 포그라운드 서비스 알림이 뜨고 거기서 중지할 수 있습니다.

### VRChat 쪽(PC로 보낼 때 필수)

1. VRChat 액션 메뉴 → Options → OSC → **Enabled**.
2. VRChat은 기본적으로 `127.0.0.1`만 수신합니다. 다른 기기에서 보내려면 실행 옵션을 추가해야 합니다(Steam → 속성 → 실행 옵션):

   ```
   --osc=9000:<PC의 LAN IP>:9001
   ```

   앱 메인 화면이 이 줄을 만들어 보여주므로 그대로 복사하면 됩니다.
3. PC 방화벽에서 UDP 9000을 허용하고, 해당 포트를 페이스트래킹 / 바디트래킹 프로그램이 쓰고 있지 않은지 확인합니다.

> 참고: OSC는 단방향이고 UDP에는 도달 확인이 없습니다. 로그의 "전송됨"은 데이터그램을 OS 네트워크 스택에 넘겼다는 뜻일 뿐입니다. 실제 도달 여부는 VRChat 액션 메뉴의 OSC Debug 패널에서 확인하세요.

## 기기 표 형식

`기기 표 설정 → 브랜드별로 만들기`: 브랜드 이름을 입력하고 JSON 파일을 고르면 그대로 `files/device_tables/<브랜드>.json`에 복사됩니다.

```json
{
  "devices": [
    { "model": "HED-AL00", "match": "exact",  "series": "Pura 80",     "verified": true },
    { "model": "LMR-AL",  "match": "prefix", "series": "Pura 80 Pro", "verified": false }
  ]
}
```

| 필드 | 필수 | 설명 |
| --- | --- | --- |
| `model` | 예 | `ro.product.model` / `Build.MODEL`에 대응하는 모델 코드, 대소문자 무시하고 비교 |
| `series` | 예 | "제품명"을 선택했을 때 표시되는 이름 |
| `match` | 아니오 | `exact`(기본, 완전 일치) 또는 `prefix`(모델이 이 값으로 시작, 파생 모델에 유용) |
| `verified` | 아니오 | 표시용 주석일 뿐, 화면에는 쓰이지 않음 |

- 최상위를 그냥 배열로 써도 됩니다. 파일은 UTF-8로 읽습니다(BOM 허용).
- 로드 순서: `files/device_tables/*.json` → 구버전 `files/device_models.json` → 내장 `assets/device_models.json`. 먼저 일치한 것이 우선.
- 제품명은 먼저 시스템 속성(`ro.product.marketname` 등)에서 가져오고, 없을 때만 기기 표를 조회합니다.

## 테마 팩 형식

`.zip`과 `.tar.gz` / `.tgz`를 지원하며, 압축을 풀면 `theme.json`이 있어야 합니다:

```
mytheme.zip
├── theme.json                 # 필수
└── images/
    ├── background.png         # 선택, 창 배경
    ├── button.png             # 선택, 버튼 기본
    └── button_pressed.png     # 선택, 버튼 눌림
```

```json
{
  "name": "야간 비행",
  "colors": {
    "background": "#0F1216",
    "card": "#1A1F24",
    "text": "#E8EAED",
    "textSecondary": "#A0A8B0"
  },
  "images": {
    "background": "images/background.png",
    "button": "images/button.png",
    "buttonPressed": "images/button_pressed.png"
  }
}
```

- `name`을 제외한 모든 항목은 선택입니다. 색은 `#RRGGBB` / `#AARRGGBB`, 이미지 경로는 테마 디렉터리 기준 상대 경로입니다.
- 테마 이름이 디렉터리 이름이 되며, 같은 이름을 다시 가져오면 덮어씁니다.
- 전환 후 앱이 자동으로 다시 시작됩니다. 설정 화면에서 길게 누르면 삭제할 수 있습니다.

## 알려진 제한

- **GPU 정보가 가장 불확실**: 안드로이드에는 GPU 주파수 / 온도 / 사용률을 얻는 공개 API가 없어 제조사별 sysfs 노드에 의존합니다. Unisoc과 일부 MediaTek 기기에서는 root가 있어도 읽지 못하고 "사용 불가"로 표시됩니다. GPU 이름은 GL `GL_RENDERER`(권한 불필요)를 우선 쓰고, 안 될 때만 sysfs로 돌아갑니다.
- **채팅창 빈도 제한**: 커뮤니티 측정으로 "5초에 5건" 정도이며 초과하면 쿨다운이 걸립니다. 기본 10초는 보수적인 값입니다.
- **비 ASCII 표시**: 전송은 항상 UTF-8이지만 VRChat 버전마다 비 ASCII 지원이 다릅니다. 확실히 보이게 하려면 "ASCII만 전송"을 켜세요.
- **Quest 독립 실행**: 설치와 실행은 되지만 Quest에는 root가 없고 Shizuku도 공식 지원이 아니라 온도 / 주파수는 거의 얻을 수 없습니다. Quest판 VRChat이 OSC 입력을 받는지는 시스템 버전에 따라 다르니 직접 확인하세요.
- **포그라운드 앱 감지**에는 시스템의 "사용 정보 접근" 권한이 필요하며, 없으면 해당 항목이 "사용 불가"로 표시됩니다.
